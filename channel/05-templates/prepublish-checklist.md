# Pre-publish checklist (10 minutes)

## Content
- [ ] `sources.md` complete; every on-screen number checked
- [ ] Watched the preview frames (`out/preview/`) or the full video once at 1.25× speed
- [ ] Hook shows the thumbnail's promise in the first 5 seconds
- [ ] Length ≥ 5:00 · captions correct · no mispronounced names (re-voice that scene: `npm run voice -- EP00N --only=s3`)

## Upload (YouTube Studio)
- [ ] Title (3 options in Test & Compare) · Thumbnail (3 variants)
- [ ] Description from `publish.md` + `chapters.txt` pasted
- [ ] Subtitles: `subtitles.ar.srt` uploaded as Arabic
- [ ] Not made for kids · Education · Arabic · altered/synthetic box per voice type
- [ ] Playlist (season) · End screen (next lesson + subscribe) · 1–2 cards to related lessons
- [ ] Scheduled for the slot (Mon/Thu 8–9 pm KSA)

## After publishing (first hour)
- [ ] Pin the question comment
- [ ] Reply to every comment
- [ ] Short #1 posted; X thread + WhatsApp card shared
- [ ] Tracker updated: `02-lessons/lessons.csv` → status `published`, `publish_date`, `video_url`

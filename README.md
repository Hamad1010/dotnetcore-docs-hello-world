# Learning App (working title)

A mobile learning app built with Expo (React Native) that teaches structured
lessons using Duolingo-style mechanics — daily lessons, quizzes with
explanations, XP, streaks, and spaced review — with its own original visual
identity.

This is a private, commercial project. See `LICENSE` — all rights reserved.

## Status

Early scaffolding stage. Screens and features are being built incrementally.

## Stack

- Expo (React Native) + TypeScript
- Expo Router (file-based navigation)
- Supabase or Firebase (backend/auth/data — to be finalized)
- RevenueCat (subscriptions)
- Expo Notifications (reminders)
- EAS Build / Submit (app store releases)

## Getting started

```
npm install
npm run start
```

Then press `i` for iOS simulator, `a` for Android emulator, or `w` for web
(scan the QR code with Expo Go on a real device instead, for the fastest
loop).

## Content

Lesson content is placeholder/sample data during early development.
Real course content will only be added once ownership, licensing, and
commercial-use permission have been confirmed with the original course
creator.
